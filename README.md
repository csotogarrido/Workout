# Workout

My personal workout plan and log: a small phone-friendly web app for a daily 15-minute home strength routine.

**Open the app:** https://csotogarrido.github.io/Workout/

## What it does

- **0 · Quick check:** a few questions (warning signs, how the last session felt, pain, cueca, breathing) plus the saved history suggest today's session: A, B, C, D or Easy.
- **1 · Choose the session:** A legs and glutes, B upper body, C core and balance, D back of the body, or the Easy mobility day.
- **2 · Do the session:** warm-up, 3 exercises with images, a relief stretch and rest timer between sets and before the next exercise, and the cool-down. Each set is marked "Done as planned" or with the reps actually done.
- **3 · Log:** pain, feel, stability and comments. History shows each session as Standard or Adapted and opens the details.

The log is stored in the phone's browser. It can also be sent to a Google Sheet with `google-sheet-script.gs` (paste it into Extensions › Apps Script of a blank sheet, deploy as a web app, and paste the link under History › Google Sheet link).
